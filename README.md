# Autlán | Dashboard de riesgos y coberturas

Dashboard académico interactivo con 10 secciones: exposición a commodities, tendencias, correlaciones, sensibilidad financiera, producción, contratos, escenarios de cobertura, simulaciones y conclusiones.

## Publicar con GitHub Pages

1. Crea un repositorio en GitHub, por ejemplo `autlan-dashboard`.
2. Sube los archivos de esta carpeta **a la raíz del repositorio**, especialmente `index.html` (no subas solamente el ZIP).
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main`, carpeta `/ (root)` y haz clic en **Save**.
6. Cuando GitHub termine de publicar, abre `https://TU-USUARIO.github.io/autlan-dashboard/` (sustituye usuario y nombre del repositorio).

## Uso local

Abre `index.html` en un navegador moderno. El sitio no requiere Node.js, npm ni instalación de dependencias.

## Notas metodológicas

- El contenido es un análisis académico, no asesoría financiera ni una estrategia de cobertura ejecutable.
- Los escenarios de sensibilidad y cobertura son estimaciones; las equivalencias físicas no garantizan efectividad de cobertura.
- Antes de publicar un repositorio público, revisa que no haya datos confidenciales ni información cuya redistribución esté restringida.
- Los enlaces externos a bolsas y fuentes de datos dependen de los sitios de terceros y pueden cambiar.
